# Maquettes UI - Clinical Storage System

## Vue d'ensemble

Interfaces utilisateur conçues pour une expérience intuitive, accessible et conforme aux standards d'accessibilité WCAG 2.1 AA.

**Principes de Design :**
- Design System : Material Design 3 adapté
- Palette de couleurs : Professionnelle médicale (bleu/blanc/gris)
- Typographie : Inter (titres), Roboto (corps)
- Responsive : Mobile-first, adaptable tablette/desktop
- Accessibilité : Contraste élevé, navigation clavier, screen reader friendly
